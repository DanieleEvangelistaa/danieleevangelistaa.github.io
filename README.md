# Daniele Evangelista — Research Portfolio

A responsive GitHub Pages portfolio for Daniele Evangelista, MD, PhD.

## Required repository name for the clean root URL

The repository must be named exactly:

`danieleevangelistaa.github.io`

The resulting address is:

`https://danieleevangelistaa.github.io/`

## Publish

1. Rename the current repository from `Website` to `danieleevangelistaa.github.io`, or create a new public repository with that exact name.
2. Upload every file and the complete `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose **main** and **/(root)**, then save.

The site uses Daniele’s official public ISHLT recipient portrait. If that image source is unavailable, a local fallback is displayed automatically.
