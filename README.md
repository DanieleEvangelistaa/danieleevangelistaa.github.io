# Daniele Evangelista — Research Portfolio

A responsive GitHub Pages website for Daniele Evangelista, MD, PhD.

## Recommended repository

Create a **public** repository in Daniele’s GitHub account with this exact name:

```text
danieleevangelistaa.github.io
```

The resulting public address will be:

```text
https://danieleevangelistaa.github.io/
```

## Upload through GitHub.com

1. Sign in to the GitHub account **DanieleEvangelistaa**.
2. Create the public repository `danieleevangelistaa.github.io`.
3. Do not add another README, `.gitignore`, or license during repository creation; all required files are already included here.
4. Unzip the supplied package.
5. In the new repository, select **Add file → Upload files**.
6. Drag all unzipped files and folders into GitHub. `index.html` must remain at the repository root.
7. Commit directly to the `main` branch.
8. Open **Settings → Pages**.
9. Under **Build and deployment**, select **Deploy from a branch**.
10. Select branch **main**, folder **/(root)**, then save.

GitHub normally publishes the site shortly after the first deployment.

## Files

- `index.html` — semantic website content and SEO metadata
- `assets/styles.css` — responsive design system
- `assets/script.js` — navigation, theme, sharing and reveal interactions
- `assets/portrait-fallback.svg` — resilient portrait fallback
- `assets/social-card.png` — social sharing artwork
- `site.webmanifest`, icons, sitemap and robots file — discoverability and mobile support
- `.nojekyll` — ensures GitHub Pages serves the files without Jekyll processing
