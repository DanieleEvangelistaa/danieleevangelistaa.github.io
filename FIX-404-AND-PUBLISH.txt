WHY THE ROOT URL SHOWED 404

The uploaded repository was named "Website". A GitHub personal Pages site at
https://danieleevangelistaa.github.io/
requires a public repository named exactly:

danieleevangelistaa.github.io

RECOMMENDED FIX — CLEAN ROOT ADDRESS

1. In DanieleEvangelistaa/Website, open Settings → General.
2. Under Repository name, rename Website to:
   danieleevangelistaa.github.io
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and /(root), then Save.
6. Replace the previous website files with all files from this package.
7. Wait several minutes and open:
   https://danieleevangelistaa.github.io/

ALTERNATIVE — KEEP THE REPOSITORY NAME WEBSITE

Enable Pages from main and /(root), then use this project-site address:
https://danieleevangelistaa.github.io/Website/

The clean root address will not work while the repository remains named Website.
